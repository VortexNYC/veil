01 — Bind the workload

veil agent bind trusts short-lived OIDC tokens from Vercel, GitHub Actions, Fly.io, Better Auth, Clerk, or WorkOS — and veil agent hydra issues a dedicated client credential for Cursor, Claude Code, Grok, and devin-cli. Zero static API keys in environment variables.

02 — Grant & rotate

The owner grants use, not possession. Agents see item names and URIs via list_items and match_items — never plaintext. veil rotate rolls keys with dual-phase overlap (or exchanges short-lived RFC 7523 assertions for Anthropic WIF so Veil never stores a static provider API key).

03 — Brokered use

fetch calls the URL with the credential injected upstream and blocks provider key-management endpoints. On Mac, fill writes into the page after Touch ID. Level-1 grants page a human; the agent polls approval_status and retries.

The boundary

  • Agents never receive secrets. Not in JSON, MCP, logs, or audit records — the transport doesn't carry them.
  • Death to static env keys. Authenticate from Vercel Functions, GitHub Actions, or Fly via ambient OIDC (createAmbientClient), or run veil mcp --self-host as a single binary on your own box.
  • The grant is the object. Per-item, per-level, per-principal. Honey tripwires (veil:honey-revoke) auto-revoke compromised agents on first touch.
  • Humans stay in the loop. Remote approval for level-1 use; Touch ID before anything leaves your Mac; Ory Kratos + Hydra + Keto for identity.
