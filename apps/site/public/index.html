01 — Native macOS app, Quick Access & AutoFill

Veil.app gives you global Quick Access (⌘⇧Space / ⌃⌥Space) in any app or browser to fill or copy passwords (⌘C), 2FA codes (⌘T), and usernames (⌘U), native macOS & iOS ASCredentialProvider AutoFill (passwords, WebAuthn P-256 passkeys, and verification codes), and Chrome, Firefox, Edge, and Safari extensions.

02 — Touch ID SSH agent & 1-click 1Password import

~/.veil/ssh.sock serves your SSH keys from a sealed local replica gated by Touch ID. Import .1pux or CSV exports in one click at app.veil.nyc, with built-in k-anonymity HIBP breach and weak/reused password reports.

03 — Principal separation (agents are not you)

veil agent bind trusts short-lived OIDC tokens from Vercel, GitHub Actions, GitLab, Google Cloud, AWS EKS, Azure, Fly.io, Better Auth, or WorkOS — and veil agent hydra mints client credentials for Cursor, Devin, and MCP (veil mcp stdio / https://veil.nyc/mcp).

04 — Brokered API use, 0-downtime rotation & outbound WIF

Agents call APIs via useItem / MCP fetch; Veil injects credentials at the edge, scrubs responses, blocks /api-keys endpoints, rotates keys on Resend/SendGrid/PostHog with dual-phase overlap, exchanges RFC 7523 assertions for Anthropic WIF, and revokes compromised agents on first touch of a veil:honey-revoke tripwire.

The boundary

  • Agents never receive secrets. Not in JSON, MCP, logs, or audit records — the transport doesn't carry them.
  • Death to static env keys & token replay. Authenticate via ambient OIDC (createAmbientClient), constrain tokens with RFC 9449 DPoP (dpop+jwt ES256 proof-of-possession), or run veil mcp --self-host as a single binary.
  • Forensic audit & honey tripwires. Every fetch, fill, and item_rotated row in GET /v1/audit/events records the exact agent_id and approval_id. Honey items (veil:honey-revoke) revoke compromised agents on first touch.
  • Humans stay in the loop. Remote approval for level-1 use and passkeys; single native Touch ID prompt before anything leaves your Mac; Ory Kratos + Hydra + Keto for identity.
