Veil

The credential broker for agents.
Your agent gets the ability to use a secret — it never gets the secret. Grants decide what it may use; humans approve the rest; every use is audited.

01 — Bind the agent

veil agent hydra issues a workload credential — no shared keys, no pasted tokens. Cursor, Claude Code, Grok, devin-cli, custom runners.

02 — Grant the item

The owner grants use, not possession. An agent sees item names and URIs via list_items and match_items — never plaintext.

03 — Brokered use

fetch calls the URL with the credential injected upstream — the response comes back, the secret doesn't. Fill writes into the page after Touch ID. Level-1 grants page a human; the agent polls approval_status and retries.

The boundary

  • Agents never receive secrets. Not in JSON, MCP, logs, or audit records — the transport doesn't carry them.
  • The grant is the object. Per-item, per-level, per-principal. Revocable. Audited.
  • Humans stay in the loop. Remote approval for level-1 use; Touch ID before anything leaves your Mac.
  • Identity is Ory. Kratos for humans, Hydra for tokens, Keto for membership — no hand-rolled auth.
