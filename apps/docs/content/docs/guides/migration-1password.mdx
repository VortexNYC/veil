title: Migrating from 1Password
description: One-shot import, Grok Bot displacement, and import caveats.
---

Veil **replaces** 1Password as the store — not Connect, not sync, not [1Password for Agents](https://1password.com/blog/1password-for-ai-agents) on the same vault.

## Import

| Source | How |
|--------|-----|
| 1Password | Items → Import **.1pux**, or `veil item import --from-op` |
| Others | CSV / JSON / zip — see [Onboarding](/guides/onboarding) |

Owner human bearer only. **Not MCP.** Repeat import skips matching rows; it does not overwrite passwords you rotated in Veil afterward.

## If you used 1Password with Grok Bot

| | 1Password × Grok | Veil × Grok |
|--|------------------|-------------|
| Channel | Grok Bot → Password Managers | [Custom MCP → Grok guide](/guides/grok) |
| Job | Website autofill | API inject |
| Approval | 1Password app (~30d per login) | Vault **Requests** (level1) or level2 |

After import: create **`grok`** agent, grant items, `veil mcp http`. Disconnect 1Password from Grok Bot if Veil is the only agent store.

## Caveats

- **Passkeys** and **Sign in with Google** logins often do not survive `.1pux` — re-register or use human fill.
- **1Password for Agents** limits (Personal/Private vault, no passkeys on Grok) differ from Veil grants + fill.
- **Attachments / SSH** — verify items after import.
