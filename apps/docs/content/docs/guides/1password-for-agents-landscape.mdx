## Not the same product

**1Password Environments MCP** (Cursor, Codex, Kiro) injects **env vars** — Veil equivalent is [MCP at veil.nyc](/guides/agents) with edge inject.

**NVIDIA OpenShell**, **Anchor Browser**, **Copilot hooks**, **GitHub Actions `op`** are dev/automation paths — see repo `docs/1password-for-agents-landscape.md` for the full map.
