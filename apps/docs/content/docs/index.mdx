## End-to-End Quickstart

```bash
# 1. Install the CLI
curl -fsSL https://veil.nyc/install.sh | sh

# 2. Import your existing 1Password vault directly from the local op CLI
veil item import --from-op

# 3. Register an agent, bind Vercel or GitHub Actions OIDC, and grant level2 use
veil agent add web-agent
veil agent bind web-agent --preset vercel --org acme --app web --claim owner_id=team_abc123
veil grant add --agent web-agent --item resend --level level2
```
