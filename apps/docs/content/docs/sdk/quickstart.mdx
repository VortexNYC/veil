Generated from the same OpenAPI contract as the [API reference](/reference).
Do not handwrite clients. `pnpm run sdk:generate`.

## TypeScript (Zero-Env Ambient OIDC on Vercel / GitHub Actions)

```bash
pnpm add @vortex-api/veil
```

```ts
import { createAmbientClient, listItems, useItem } from "@vortex-api/veil";

// Automatically resolves x-vercel-oidc-token, VERCEL_OIDC_TOKEN_FILE,
// GitHub Actions ACTIONS_ID_TOKEN_REQUEST_URL, or VEIL_OIDC_TOKEN.
const client = createAmbientClient();

const listed = await listItems({ client });
const used = await useItem({
  client,
  body: {
    item: "stripe",
    url: "https://api.stripe.com/v1/customers",
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ email: "bot@veil.nyc" }),
  },
});
```

Or pass an explicit bearer token via `createClient`:

```ts
import { createClient } from "@vortex-api/veil";

const client = createClient({
  baseUrl: "https://veil.nyc",
  headers: { Authorization: `Bearer ${process.env.VEIL_OIDC_TOKEN}` },
});
```

## Python

```bash
pip install vortex-api-veil
```

```py
import os
import veil

configuration = veil.Configuration(host="https://veil.nyc")
configuration.access_token = os.environ["VEIL_OIDC_TOKEN"]
api = veil.AgentApi(veil.ApiClient(configuration))
api.list_items()
api.use_item(veil.UseRequest(item="stripe", url="https://api.stripe.com/v1/customers"))
```

## Go

```bash
go get github.com/VortexNYC/veil/sdks/go
```

```go
cfg := veil.NewConfiguration()
cfg.Host = "veil.nyc"
cfg.Scheme = "https"
cfg.AddDefaultHeader("Authorization", "Bearer "+os.Getenv("VEIL_OIDC_TOKEN"))
client := veil.NewAPIClient(cfg)
_, _, _ = client.AgentAPI.ListItems(context.Background()).Execute()
```

## What the SDK does not do

It does not reveal vault material. `run`, `gen`, and `item write` stay on the owner CLI.
